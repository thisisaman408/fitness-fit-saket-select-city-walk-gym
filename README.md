# Fitness First Iconic, Saket — Concept Site

I build premium, conversion-focused websites for businesses — landing pages that load fast on mobile, sell the brand in the first scroll, and turn attention into appointments.

This is one of those builds: a full landing-page concept for **Fitness First Iconic, Saket** (the brand's flagship 20,000 sq ft Iconic club inside Select Citywalk, New Delhi). Built as a sales demo. Not affiliated with Fitness First.

> **Live demo**: deploying to Vercel — link goes here once it's live.

## What this site does

- Sells the club in the first viewport (premium dark aesthetic, real interior photography, animated cinematic hero)
- Walks the visitor through every zone of the club, the programs, the coaches, the classes, the facilities
- Embeds the brand's real YouTube channel so prospects can see the floor in motion
- Pinpoints the location on a map, lists hours, all 3 phone numbers, the email
- Captures leads via a 1-tap WhatsApp deep-link AND a trial-pass form that saves to the sales team's lead inbox
- Floating WhatsApp button + sticky bottom CTA bar so a prospect is never more than one tap from talking to the team
- Fully responsive — designed mobile-first, polished on desktop
